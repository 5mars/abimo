```swift
// Action controls below button
VStack(spacing: 14) {
    // Primary CTA: only shown when recording is stopped and file exists
    if viewModel.recordingFileURL != nil && !viewModel.isRecording {
        GradientButton(
            title: "Lock it in",
            isLoading: viewModel.isSaving
        ) {
            showingSaveDialog = true
        }
        .padding(.horizontal, 32)
    }

    // Discard pill: visible whenever any recording state is active (D-06/D-07/D-08)
    if viewModel.isRecording || viewModel.recordingFileURL != nil {
        Button {
            viewModel.cancelRecording()
        } label: {
            Text("Discard")
                .font(.system(size: 15, weight: .medium))
                .foregroundColor(.brandRed)
                .padding(.horizontal, 24)
                .padding(.vertical, 12)
                .background(Color.brandRed.opacity(0.08))
                .clipShape(Capsule())
        }
        .buttonStyle(PlayfulButtonStyle())
        .disabled(viewModel.isSaving)
        .frame(minHeight: 44)
    }

    // Idle hint
    if !viewModel.isRecording && viewModel.recordingFileURL == nil {
        Text("Tap the mic, start talking")
            .font(.system(size: 13, weight: .medium))
            .foregroundColor(Color.textSec.opacity(0.6))
    }
}
.frame(minHeight: 60)
```

Key details:
- Pill vertical padding is 12pt top and bottom, with `.frame(minHeight: 44)` enforcing 44pt touch target (per UI-SPEC).
- Pill foreground: `.brandRed` (#F87171). Background: `Color.brandRed.opacity(0.08)` — faint tint, secondary to GradientButton.
- `Capsule()` clipShape matches the status pill pattern already in RecordingView (line 33).
- `PlayfulButtonStyle()` gives scale-on-press feedback matching the idle record button.
- `.disabled(viewModel.isSaving)` prevents discard during save (per RESEARCH.md Pitfall 3).
- Hint text font changed from `.system(size: 14)` to `.system(size: 13, weight: .medium)` per UI-SPEC typography contract (caption tier).
- No explicit `.animation()` on the pill — inherits existing VStack state-change animations.

Also update the save dialog per UI-SPEC copywriting contract:

- Change `Button("Cancel", role: .cancel)` to `Button("Keep Editing", role: .cancel)`
