**File 1: Abimo/Services/SupabaseService.swift**

Add a `deleteAccount()` method in a new `// MARK: - Account Deletion` section after the existing `// MARK: - Commitments` section (after line 417). This method:

1. Gets current user session to extract userId
2. Lists and deletes all files in `voice-recordings/{userId}/` storage bucket
3. Calls the `delete_user_account` RPC function which handles all database table deletions and auth.users deletion server-side

```swift
// MARK: - Account Deletion

func deleteAccount() async throws {
    let session = try await client.auth.session
    let userId = session.user.id

    // Delete storage files first (RPC won't handle storage)
    let files = try await client.storage
        .from("voice-recordings")
        .list(path: "\(userId)")
    if !files.isEmpty {
        let paths = files.map { "\(userId)/\($0.name)" }
        try await client.storage
            .from("voice-recordings")
            .remove(paths: paths)
    }

    // Delete all user data + auth record via server-side RPC
    try await client.rpc("delete_user_account").execute()
}
```

**File 2: Abimo/ViewModels/AuthViewModel.swift**

Add a `deleteAccountAndSignOut()` method after the existing `signOut()` method (after line 101). Per DATA-02.

IMPORTANT: Do NOT call `signOut()` after deletion -- the user no longer exists server-side, so `signOut()` will throw. Instead, clear local auth state directly (per Pitfall 1 from research -- Supabase Swift Issue #358/#404).

```swift
func deleteAccountAndSignOut() async {
    isLoading = true
    errorMessage = nil
    defer { isLoading = false }

    do {
        try await supabase.deleteAccount()
        // User no longer exists on server -- just clear local state
        // Do NOT call signOut() -- it will fail for deleted user
        currentUser = nil
        isAuthenticated = false
    } catch {
        errorMessage = "Account deletion failed: \(error.localizedDescription)"
    }
}
```

Also add a `clearLocalData()` method right after `deleteAccountAndSignOut()`. This wipes all UserDefaults using `removePersistentDomain` (not individual keys -- per Pitfall 3 from research) then re-registers notification defaults so toggles reset to ON. Per DATA-03.

```swift
func clearLocalData() {
    guard let bundleId = Bundle.main.bundleIdentifier else { return }
    UserDefaults.standard.removePersistentDomain(forName: bundleId)
    UserDefaults.standard.register(defaults: [
        "notif_inactivity": true,
        "notif_action_nudge": true,
        "notif_idea_nudge": true,
        "notif_streak": true
    ])
}
```
